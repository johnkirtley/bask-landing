# Canonical blog backlog

Ordered informational topics from `src/content/bask_content_outlines.md` that are **not** already in `content-loops/topics-covered.md` or `content-loops/posts/`. The Topic Strategist uses this when Reddit is empty and the open writing queue has fewer than three unwritten `Open` briefs.

**How to use**

1. Skip rows whose slug is already published, drafted, or in the priority queue as `Open`.
2. Prefer the first row that passes seasonality (see blueprint) and dedup.
3. **Audience evidence** for a backlog row counts toward bar #6 without Reddit: the blueprint primary keyword is a validated query intent; cite the matching phrase from `bask-seo-autocomplete-research.md` when one exists, otherwise cite the blueprint primary keyword explicitly.
4. **Rankability** must still be checked each cycle. When Google Search is JavaScript-blocked, use headless SERP sampling via `curl` against Bing (`https://www.bing.com/search?q=...`) or another HTML search engine, and describe who ranks honestly. Do not claim Google-specific rankings from Bing alone — phrase it as "Bing sample suggests …; re-check in browser when available."
5. Open at most **one** backlog topic per deadlock-breaking cycle.
